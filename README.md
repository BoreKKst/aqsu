# AqSu — ғылыми жоба сайты

Бұл жоба бір HTML файлға жиналмаған: HTML, CSS және JavaScript бөлек файлдарға бөлінген.

## Қапшық құрылымы

```text
AqSu-Website/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── app.js
├── assets/
└── README.md
```

## Іске қосу

1. `AqSu-Website` папкасын ашыңыз.
2. `index.html` файлын браузермен ашыңыз.
3. Интернет қосулы болса, тақырып қарпі Google Fonts арқылы жүктеледі. Қаріп жүктелмесе, сайт жүйелік қаріптерді қолданады.

## GitHub Pages-ке жариялау

1. GitHub-та жаңа репозиторий ашыңыз.
2. Осы папканың ішіндегі файлдар мен папкаларды репозиторийдің түбіріне жүктеңіз.
3. Репозиторийден **Settings → Pages** бөліміне өтіңіз.
4. **Deploy from a branch** таңдаңыз.
5. Branch ретінде `main`, папка ретінде `/ (root)` таңдаңыз да, Save басыңыз.

## Ескерту

Симулятор — браузердегі демонстрациялық модель, нақты сенсорға немесе сорғыға қосылмаған. Сынақ кестесі мен смета бастапқы жоба мәтінінде берілген деректер ретінде көрсетілген.
